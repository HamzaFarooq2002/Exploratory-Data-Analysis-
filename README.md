Exploratory Data Analysis (EDA) Projects

This repository contains my Exploratory Data Analysis (EDA) projects where I analyze real-world datasets to extract insights using Python.

The objective of these projects is to practice data cleaning, visualization, statistical analysis, and deriving meaningful conclusions from raw data.

Tools & Technologies Used

Python

Pandas

NumPy

Matplotlib / Seaborn

Jupyter Notebook

Key Focus Areas

Data preprocessing and cleaning

Handling missing values

Feature exploration

Statistical summaries

Data visualization

Insight generation

Each folder in this repository represents a separate EDA project with its own dataset and analysis notebook.
